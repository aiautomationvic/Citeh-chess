# Citeh Chess

A fan-made Lichess client for phones. Log in with your own Lichess account to play.

Analysis runs Stockfish in your browser: Stockfish 10 (stockfish.js) as the fast default and Stockfish 19 lite (NNUE) as the optional strong engine. Both are GPLv3, see site/stockfish-COPYING.txt. Engine help is only offered after a game ends or on the analysis board.
